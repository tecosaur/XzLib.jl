Read and write =.xz= data with [[https://github.com/BioJulia/BufferIO.jl][BufferIO.jl]], including random access into files
split into Blocks.

#+begin_src julia
using XzLib

text = "Lorem ipsum dolor sit amet,\nconsectetur adipiscing elit."

# Whole buffers
compressed = compress_xz(text)
decompress_xz(compressed) == codeunits(text)  # true

# Streams
XzWriter(open("lorem.txt.xz", "w")) do writer
    write(writer, text)
end
XzReader(open("lorem.txt.xz")) do reader
    for line in eachline(reader)
        println(line)
    end
end
#+end_src

~XzWriter~ is a BufferIO ~AbstractBufWriter~, and both readers are
~AbstractBufReader~ subtypes. Wrap a reader in ~BufferIO.IOReader~ to use it as a
~Base.IO~.

* Random access

~XzSeekableReader~ reads the file's Index when opened. ~seek~, ~skip~, and
~position~ work in uncompressed offsets, and a read decodes from the start of the
Block containing its first byte, so smaller Blocks make random reads faster.

#+begin_src julia
compressed = compress_xz(data; blocksize=1_000_000)
reader = XzSeekableReader(IOBuffer(compressed))
seek(reader, 5_000_000)
read(reader, 100)
#+end_src

* Threads

~XzWriter~ and ~XzReader~ use liblzma's threads, by default one per CPU.
~XzSeekableReader~ decodes Blocks on Julia's threads, so start Julia with =-t=
for parallel decoding. All three limit their parallelism to keep memory use
within a quarter of RAM.

With more than one thread, ~XzWriter~ writes each Block once it is complete.
With one thread, it writes output as input arrives.
