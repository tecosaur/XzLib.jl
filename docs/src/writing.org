#+title: Writing

[[@ref][~XzWriter~]] is a BufferIO ~AbstractBufWriter~ that compresses data to =.xz= as you
write it. Its sink is an ~AbstractBufWriter~, with a plain ~IO~ wrapped in a
~BufWriter~ first, just as the readers wrap their source. Closing it finishes the
=.xz= data and closes the sink, and ~flush~ ends the current Block, so that
everything written so far can be decoded.

* Whole buffers

[[@ref][~compress_xz~]] compresses anything ~write~ accepts in one call, and takes the same
keywords as ~XzWriter~.
