Writing

XzWriter is a BufferIO AbstractBufWriter that compresses what is written to it. Like the readers, it writes to an AbstractBufWriter, wrapping a plain IO in a BufWriter first. Closing it finishes the .xz data and closes the sink, and flush ends the current Block, so that everything written so far can be decoded.

XzLib.XzWriter — Type
XzWriter(sink::Union{IO, AbstractBufWriter}; level=6, check=:crc64, threads=0, blocksize=nothing, bufsize=65536)
XzWriter(f, sink; kwargs...)

Create an AbstractBufWriter that compresses what is written to it, writing the .xz data to sink.

flush ends the current Block, so that everything written so far can be decoded. close finishes the .xz data and closes sink. The second form calls f on the writer then closes it, unless f throws, in which case the .xz data are left unfinished so that they don't pass for complete. Likewise, if encoding or writing to sink fails, the writer closes itself and sink, leaving the .xz data unfinished.

Arguments

  • level: compression preset, from 0 (fastest) to 9 (smallest)
  • check: integrity check, one of :none, :crc32, :crc64, or :sha256
  • threads: number of liblzma threads, or 0 for one per available CPU like xz -T0; either way reduced as needed to keep memory usage within a quarter of RAM
  • blocksize: uncompressed bytes per Block. The default matches xz: three times the dictionary size, and at least 1 MiB (24 MiB at level 6). Smaller Blocks compress slightly worse but make seeking in XzSeekableReader cheaper. 0 writes a single Block, on one thread.
  • bufsize: size of the input buffer in bytes

With one thread, output is written as input arrives. With more, each Block is written once it is complete, recording its sizes, which lets liblzma decode it on its own thread.

Throws ArgumentError for invalid arguments, and XzError if liblzma fails.

Examples

julia> using XzLib

julia> path = tempname();

julia> XzWriter(open(path, "w"); level=9) do writer
           write(writer, "Hello, world!")
       end
13

julia> String(decompress_xz(read(path)))
"Hello, world!"

Whole buffers

compress_xz compresses anything write accepts in one call, and takes the same keywords as XzWriter.

XzLib.compress_xz — Function
compress_xz(data; kwargs...)::Vector{UInt8}

Compress data, anything write accepts, to .xz. The keyword arguments are those of XzWriter.

Examples

julia> using XzLib

julia> compressed = compress_xz("Hello, world!");

julia> String(decompress_xz(compressed))
"Hello, world!"
