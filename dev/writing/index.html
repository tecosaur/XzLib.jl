Writing

XzWriter is a BufferIO AbstractBufWriter that compresses what is written to it. Like the readers, it wraps an AbstractBufWriter or an IO, and closing it finishes the .xz data and closes the sink. flush ends the current Block, so that everything written so far can be decoded.

julia> XzWriter(open("hello.txt.xz", "w")) do writer
           write(writer, "Hello, world!")
       end
13

If the function passed to XzWriter throws, the .xz data is left unfinished, so that it isn't mistaken for complete data.

Options

KeywordDefaultMeaning
level6Compression preset, from 0 (fastest) to 9 (smallest)
check:crc64Integrity check: :none, :crc32, :crc64 or :sha256
threads0liblzma threads, with 0 for one per CPU
blocksizethree times the dictionary size, at least 1 MiBUncompressed bytes per Block, with 0 for one Block

Smaller Blocks make random access with XzSeekableReader faster, and compress slightly worse. With more than one thread, XzWriter writes each Block once it is complete, recording its size. With one thread, it writes output as input arrives.

Whole buffers

compress_xz and decompress_xz take the same keywords as XzWriter and XzReader.

julia> compressed = compress_xz("Hello, world!"; level=9);

julia> String(decompress_xz(compressed))
"Hello, world!"
