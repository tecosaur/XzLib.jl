#+title: Reading

XzLib has two readers, both BufferIO readers (~AbstractBufReader~):

+ [[@ref][~XzReader~]] decompresses =.xz= data as it is read, from any source, including
  pipes and sockets. With more than one thread, it decodes Blocks in parallel when
  they record their sizes.
+ [[@ref][~XzSeekableReader~]] reads the Index of complete =.xz= data from a seekable
  source, and then supports ~seek~, ~skip~, ~position~ and ~filesize~ in uncompressed
  offsets. It decodes Blocks ahead on Julia's threads, whether or not they record
  their sizes.

For files, use ~XzSeekableReader~ with Julia started with several threads (=-t=).
For streams, or with a single Julia thread, use ~XzReader~.

Both wrap an ~AbstractBufReader~, or wrap an ~IO~ in a ~BufReader~ first. Closing a
reader closes its source, and passing a function as the first argument calls it
on the reader and then closes it.

* Random access

A read from ~XzSeekableReader~ decodes from the start of the Block containing its
first byte, so files written with smaller Blocks seek faster.

* Errors

Corrupt or truncated data throws an [[@ref][~XzError~]]. An ~XzReader~ throws the same
error on every later read, while an ~XzSeekableReader~ can be recovered by seeking.
