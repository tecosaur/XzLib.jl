#+title: Writing

[[@ref][~XzWriter~]] is a BufferIO ~AbstractBufWriter~ that compresses what is written to
it. Like the readers, it writes to an ~AbstractBufWriter~, wrapping a plain ~IO~
in a ~BufWriter~ first. Closing it finishes the =.xz= data and closes the sink,
and ~flush~ ends the current Block, so that everything written so far can be
decoded.

* Whole buffers

[[@ref][~compress_xz~]] compresses anything ~write~ accepts in one call, and takes the same
keywords as ~XzWriter~.
