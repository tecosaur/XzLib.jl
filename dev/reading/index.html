Reading

XzLib has two readers, both BufferIO readers (AbstractBufReader):

  • XzReader decompresses .xz data as it is read, from any source, including pipes and sockets. With more than one thread, it decodes Blocks in parallel when they record their sizes.
  • XzSeekableReader reads the Index of complete .xz data from a seekable source, and then supports seek, skip, position and filesize in uncompressed offsets. It decodes Blocks ahead on Julia's threads, whether or not they record their sizes.

For files, use XzSeekableReader with Julia started with several threads (-t). For streams, or with a single Julia thread, use XzReader.

Both wrap an AbstractBufReader, or wrap an IO in a BufReader first. Closing a reader closes its source, and passing a function as the first argument calls it on the reader and then closes it.

XzLib.XzReader — Type
XzReader(source::Union{IO, AbstractBufReader}; threads=0, memlimit=typemax(UInt64), bufsize=65536)
XzReader(f, source; kwargs...)

Create an AbstractBufReader that decompresses the .xz data read from source, which may be several concatenated .xz streams. The second form calls f on the reader then closes it.

For random access, see XzSeekableReader.

Arguments

  • threads: number of liblzma decoding threads, or 0 for one per available CPU. Blocks decode in parallel only when they record their sizes (see XzWriter).
  • memlimit: memory usage limit as bytes
  • bufsize: size of the output buffer as bytes

Throws ArgumentError for invalid arguments, and XzError if the data are corrupt, after which reads throw the same error.

Examples

julia> using XzLib

julia> reader = XzReader(IOBuffer(compress_xz("Hello, world!")));

julia> read(reader, String)
"Hello, world!"

Random access

A read from XzSeekableReader decodes from the start of the Block containing its first byte, so files written with smaller Blocks seek faster.

XzLib.XzSeekableReader — Type
XzSeekableReader(source::Union{IO, AbstractBufReader}; threads=Threads.nthreads(), memlimit=typemax(UInt64), bufsize=65536)
XzSeekableReader(f, source; kwargs...)

Create a seekable AbstractBufReader that decompresses the .xz data source is positioned at the start of, which must extend to the end of source. The second form calls f on the reader then closes it.

seek, skip, position, and filesize all work in uncompressed offsets. Seeking itself is cheap: the next read decodes from the start of the Block holding its first byte, so its cost is bounded by the file's Block size (see blocksize in XzWriter), and forward seeks within the current Block decode on rather than restart. Once reading proves sequential, up to threads of the following Blocks are decoded ahead on worker tasks, in parallel when Julia has several threads.

Wrap the reader in BufferIO.IOReader to pass it where a Base.IO is expected.

Arguments

  • source: seekable IO holding .xz data
  • threads: maximum number of Blocks to decode ahead, with 1 decoding only on the reading task
  • memlimit: memory usage limit per Block decoder as bytes
  • bufsize: size of the output buffer as bytes

Throws ArgumentError for invalid arguments, XzError if the .xz Index cannot be read, and XzError while reading if the data are corrupt, after which reads throw until the next seek.

Examples

julia> using XzLib

julia> data = repeat(b"0123456789", 100_000);

julia> reader = XzSeekableReader(IOBuffer(compress_xz(data; blocksize=100_000)));

julia> seek(reader, 654_321);

julia> String(read(reader, 4))
"1234"

Errors

Corrupt or truncated data throws an XzError. An XzReader throws the same error on every later read, while an XzSeekableReader can be recovered by seeking.

XzLib.XzError — Type
XzError <: Exception

Failure to encode or decode .xz data while attempting operation on Block number block (0 when the failure is not specific to one Block), with the liblzma status code that caused it.
