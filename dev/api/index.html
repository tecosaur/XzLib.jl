API

XzLib — Module

xz compression and decompression on BufferIO.

  • XzWriter compresses what is written to it.
  • XzReader decompresses a stream of .xz data.
  • XzSeekableReader decompresses seekable .xz data with random access.
  • compress_xz and decompress_xz work on whole buffers.
  • XzError reports liblzma failures.

Writing

XzLib.XzWriter — Type
XzWriter(sink::Union{IO, AbstractBufWriter}; level=6, check=:crc64, threads=0, blocksize=nothing, bufsize=65536)
XzWriter(f, sink; kwargs...)

Create an AbstractBufWriter that writes the .xz compression of what is written to it to sink.

flush ends the current Block, so that everything written so far can be decoded. close finishes the .xz data and closes sink. The second form calls f on the writer then closes it, unless f throws, in which case the .xz data are left unfinished so that they don't pass for complete.

Arguments

  • level: compression preset, from 0 (fastest) to 9 (smallest)
  • check: integrity check, one of :none, :crc32, :crc64, or :sha256
  • threads: number of liblzma threads, or 0 for one per available CPU like xz -T0; either way reduced as needed to keep memory usage within a quarter of RAM
  • blocksize: uncompressed bytes per Block, by default xz's: three times the dictionary size, and at least 1 MiB (24 MiB at level 6). Smaller Blocks compress slightly worse but make seeking in XzSeekableReader cheaper. 0 writes a single Block, on one thread.
  • bufsize: size of the input buffer as bytes

With one thread, output is written as input arrives. With more, each Block is written once it is complete, recording its sizes, which lets liblzma decode it on its own thread.

Throws ArgumentError for invalid arguments, and XzError if liblzma fails.

Examples

julia> using XzLib

julia> path = tempname();

julia> XzWriter(open(path, "w"); level=9) do writer
           write(writer, "Hello, world!")
       end
13

julia> String(decompress_xz(read(path)))
"Hello, world!"

Reading

XzLib.XzReader — Type
XzReader(source::Union{IO, AbstractBufReader}; threads=0, memlimit=18446744073709551615, bufsize=65536)
XzReader(f, source; kwargs...)

Create an AbstractBufReader that decompresses the .xz data read from source, which may be several concatenated .xz streams. The second form calls f on the reader then closes it.

For random access, see XzSeekableReader.

Arguments

  • threads: number of liblzma decoding threads, or 0 for one per available CPU. Blocks decode in parallel only when they record their sizes (see XzWriter).
  • memlimit: memory usage limit as bytes
  • bufsize: size of the output buffer as bytes

Throws ArgumentError for invalid arguments, and XzError if the data are corrupt, after which reads throw the same error.

Examples

julia> using XzLib

julia> reader = XzReader(IOBuffer(compress_xz("Hello, world!")));

julia> read(reader, String)
"Hello, world!"

XzLib.XzSeekableReader — Type
XzSeekableReader(source::Union{IO, AbstractBufReader}; threads=Threads.nthreads(), memlimit=18446744073709551615, bufsize=65536)
XzSeekableReader(f, source; kwargs...)

Create a seekable AbstractBufReader that decompresses the .xz data source is positioned at the start of, which must extend to the end of source. The second form calls f on the reader then closes it.

seek, skip, position, and filesize all work in uncompressed offsets. Seeking itself is cheap: the next read decodes from the start of the Block holding its first byte, so its cost is bounded by the file's Block size (see blocksize in XzWriter), and forward seeks within the current Block decode on rather than restart. Once reading proves sequential, up to threads of the following Blocks are decoded ahead on worker tasks, in parallel when Julia has several threads.

Wrap the reader in BufferIO.IOReader to pass it where a Base.IO is expected.

Arguments

  • source: seekable IO holding .xz data
  • threads: maximum number of Blocks to decode ahead, with 1 decoding only on the reading task
  • memlimit: memory usage limit per Block decoder as bytes
  • bufsize: size of the output buffer as bytes

Throws XzError if the .xz Index cannot be read, and while reading if the data are corrupt, after which reads throw until the next seek.

Examples

julia> using XzLib

julia> data = repeat(b"0123456789", 100_000);

julia> reader = XzSeekableReader(IOBuffer(compress_xz(data; blocksize=100_000)));

julia> seek(reader, 654_321);

julia> String(read(reader, 4))
"1234"
