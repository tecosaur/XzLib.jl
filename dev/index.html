XzLib.jl

Read and write .xz data with BufferIO.jl, including random access into files split into Blocks.

using XzLib

# Compress a file
XzWriter(open("data.xz", "w")) do writer
    write(writer, read("data"))
end

# Decompress it
data = XzReader(read, open("data.xz"))

# Read 100 bytes from the middle
XzSeekableReader(open("data.xz")) do reader
    seek(reader, 5_000_000)
    read(reader, 100)
end
XzLib — Module
XzLib

xz compression and decompression on BufferIO.

  • XzWriter compresses what is written to it.
  • XzReader decompresses a stream of .xz data.
  • XzSeekableReader decompresses seekable .xz data with random access.
  • compress_xz and decompress_xz work on whole buffers.
  • XzError reports liblzma failures.

Comparison with CodecXz

CodecXz.jl provides .xz codecs for TranscodingStreams.jl, and is the one to use with other TranscodingStreams packages. XzLib started as a rewrite of CodecXz. It uses BufferIO's interface instead, and adds random access and parallel decoding of any multi-Block file.
